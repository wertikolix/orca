# Orca 0.9.5

This release makes Orca smaller and safer for production Compose applications.

## Highlights

- Removes Android consumer keep-all rules so R8 can strip unused Orca rendering and parsing code.
- Blocks remote image loads by default; trusted callers can opt in with `OrcaSecurityPolicies.RemoteImages` or a custom policy.
- Parses raw Markdown off the UI thread from initial composition onward.
- Keeps token streaming responsive by rendering the latest conflated input at the pacing interval instead of waiting for an idle gap.
- Removes the Material3 dependency from `orca-compose` by rendering text with Compose Foundation.
- Corrects public dependency exposure for Compose and the Markdown parser backend.

## Measured impact

In a release build of the Fish Android application, changing only the Orca consumer shrinker rules reduced the APK by approximately 116 KiB and removed approximately 111 KiB from `classes.dex`.

## Migration note

Applications that intentionally render remote Markdown images must explicitly opt in:

```kotlin
Orca(
    document = document,
    securityPolicy = OrcaSecurityPolicies.RemoteImages,
)
```
