# Orca 0.11.0

This development line adds optional native LaTeX rendering without adding a math engine or font to the base renderer.

## Highlights

- Adds `OrcaInline.Math` and `OrcaBlock.Math` for conservative `$...$` and `$$...$$` parsing.
- Adds `inlineMathContent` and `blockMathContent` slots to `orca-compose`.
- Adds Android-only `orca-math-orcex`, backed by Orcex's native Canvas renderer.
- Uses Orcex `0.2.1`, including corrected matrix delimiter alignment.
- Preserves readable source text for incomplete math delimiters during streaming.
- Avoids interpreting `$$` content inside fenced code blocks as formulas.

## Weight Strategy

`orca-core` and `orca-compose` remain free from Orcex and STIX font dependencies. Consumers enable native formula rendering only when their product needs it.
