# Orca 0.11.1

Patch release fixing Maven Central publication of the optional Android math renderer.

## Fixed

- Removes the redundant direct `androidx.compose.ui:ui` dependency emitted without a version in the `orca-math-orcex` POM.
- Retains Compose UI transitively through `orca-compose`, which already publishes versioned Compose dependencies.
- Continues to use Orcex `0.2.1` for corrected matrix delimiter alignment.
