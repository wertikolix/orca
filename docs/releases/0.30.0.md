# Orca 0.30.0

## Highlights

- **Flat design system:** `orcaFlatStyle(palette, density, …)` builds a complete `OrcaStyle` from color tokens. `OrcaPalette` covers surfaces, outlines, text, one accent, a `syntax` palette for code, and a `signal` palette with one color per admonition type. Four presets ship in `OrcaPalettes`: `FlatLight`, `FlatDark`, `ContrastLight`, `ContrastDark`. The system has no elevation, gradient, or shadow token, by construction.
- **Density scale:** `OrcaDensity.COMPACT | COMFORTABLE | SPACIOUS` scales block spacing and container padding without touching text metrics, so line lengths stay predictable. Accepted by `orcaFlatStyle`, every `OrcaDefaults` style factory, and the Material 3 adapter.
- **New visual defaults:** `OrcaDefaults.lightStyle()` and `darkStyle()` now return flat styles, `adaptiveContrastStyle()` targets accessibility surfaces, and `legacyLightStyle()` / `legacyDarkStyle()` preserve the pre-0.30 look for pinned screenshots.
- **Heading rules:** `OrcaHeadingRuleStyle` renders a one-pixel rule under selected heading levels — H1 and H2 by default in flat styles, opt-out with an empty level set.
- **Document search:** `OrcaDocument.findMatches()` returns every hit with its top-level block index, the nearest heading anchor, and an elided snippet. Case sensitivity, whole-word matching, result limits, and snippet radius are configurable.
- **Search highlighting:** `OrcaTextHighlight` on every `Orca` overload shades matches with `OrcaInlineStyle.searchMatch` across headings, paragraphs, list items, table cells, definition terms, details summaries, and footnote bodies. Code blocks keep their syntax colors.
- **Document statistics:** `OrcaDocument.stats()` reports words, characters, reading time, per-block-type counts, and task progress in a single traversal.
- **Plain text export:** `OrcaDocument.plainText()`, `OrcaBlock.plainText()`, and `List<OrcaInline>.plainText()` are now public API.
- **Material 3 adapter refresh:** `rememberOrcaMaterialStyle(density, headingRules)` maps the active color scheme into an `OrcaPalette` through `OrcaDefaults.materialPalette()` and builds the style with `orcaFlatStyle`, so Material hosts render with the same flat system.
- **Render lab:** ten suites, one token system shared by the app chrome and the renderer, in-document search with match navigation, live statistics, palette and density switches, a design-token suite, and snippet insertion in the playground.
- **Release workflow:** the Maven Central publish window is much longer — job timeout raised to 120 minutes, per-step timeouts added, the staging publish trigger retries with exponential backoff, and sync verification runs under one bounded window instead of a per-artifact loop.

## New API

```kotlin
// Flat tokens in, complete style out.
val style = orcaFlatStyle(
    palette = OrcaPalettes.FlatDark.copy(accent = Color(0xFF8FD3CE)),
    density = OrcaDensity.COMPACT,
    headingRuleLevels = setOf(1, 2),
)

// Search the document, highlight the hits, jump between them.
val matches = document.findMatches(query, OrcaSearchOptions(wholeWord = true))

Orca(
    document = document,
    listState = listState,
    style = style,
    highlight = OrcaTextHighlight(query),
)

scope.launch { listState.animateScrollToItem(matches[cursor].blockIndex) }

// Measure the document.
val stats = document.stats()
println("${stats.words} words · ${stats.readingMinutes} min · ${stats.completedTasks}/${stats.tasks} tasks")
```

## Migration

All new parameters and style fields have defaults, so existing named `Orca(…)` calls and
`OrcaStyle(…)` constructions keep compiling.

The visible change is the default look. `OrcaDefaults.lightStyle()`, `OrcaDefaults.darkStyle()`,
`OrcaDefaults.adaptiveStyle()`, and the `style` default of every `Orca` overload now produce the
flat 0.30 system: warm neutral surfaces, a single teal accent, one-pixel outlines, zebra tables,
and rules under H1/H2. Applications with screenshot tests should either refresh their snapshots or
switch to `OrcaDefaults.legacyLightStyle()` / `legacyDarkStyle()`.

The raw `OrcaStyle()` constructor still returns the previous per-field defaults; only the
`OrcaDefaults` factories moved to the flat palettes.

Material 3 hosts keep calling `rememberOrcaMaterialStyle()`. The mapping now goes through
`materialPalette()`, so code backgrounds come from `surfaceContainerLow`, table headers from
`surfaceContainerHigh`, and the table overflow indicator from `primary`.
