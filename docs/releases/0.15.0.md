# Orca 0.15.0

## Highlights

- **Incremental streaming v2** — `OrcaIncrementalParserSession` now reuses far more of the completed stream. Instead of the paragraphs-only fast path, the session splits the stream into blank-line separated segments (with fenced code treated atomically) and freezes headings, closed fences, lists, quotes, admonitions, tables, and thematic breaks as soon as later content can no longer affect them. Only the active tail is re-parsed per token batch. Heading anchor slugs are re-derived across the merged document, so duplicate titles keep exact full-parse numbering. Correctness is enforced by prefix-equivalence property tests that compare every streamed prefix against the full parser at multiple chunk sizes.
- **Text selection in `LAZY_COLUMN`** — the default lazy root layout now sits inside a `SelectionContainer`, so long documents are selectable just like the `COLUMN` mode.
- **Table of contents API** — new `OrcaDocument.tableOfContents(maxLevel)` in `orca-core` returns levels, plain-text titles, and anchor ids; new `orcaHeadingBlockIndex(document)` in `orca-compose` maps those ids to top-level lazy-list indices for `LazyListState.animateScrollToItem`.
- **Streaming cursor** — new optional `streamingCursor` parameter on all `Orca` overloads renders a cursor glyph (e.g. `▍`) after the last block; the `OrcaStreamingState` overload shows it only while streaming. The cursor is applied to the parsed document — never to the source — keeping incremental parser sessions append-only.
- **Admonition icons** — callout titles now render a theme-tinted monochrome glyph (ℹ ✦ ◆ ▲ ■) before the title. Configure or disable via `OrcaAdmonitionStyle.showIcons`, `iconSpacing`, and per-type icon strings.
- **Orcex 0.5.0** — `orca-math-orcex` picks up the new Orcex release: LaTeX colors (`\textcolor{red}{...}`, `\color{#FF8800}`), framed results (`\boxed{...}`), stacked annotations (`\overset`/`\underset`), and wasmJs artifacts of the Orcex runtime.

## Migration

No breaking API changes. New `Orca` parameters are optional with unchanged defaults; `OrcaAdmonitionStyle` gains icon fields (set `showIcons = false` to restore the 0.14 look).

```kotlin
// Table of contents driving the reader scroll position:
val doc = parser.parse(markdown)
val toc = doc.tableOfContents(maxLevel = 2)
val anchors = orcaHeadingBlockIndex(doc)
toc.forEach { entry -> /* chip: scroll to anchors[entry.id] */ }

// LLM chat bubble with a live cursor:
Orca(state = stream, parser = session, streamingCursor = "\u258D")
```
