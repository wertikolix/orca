# Orca 0.12.0

Minor release making optional Orcex math rendering multiplatform.

## Updated

- Migrates `orca-math-orcex` from its Android-only Canvas bridge to the official `orcex-render-compose` backend from Orcex `0.4.0`.
- Publishes the optional math adapter for Android, Desktop, iOS Arm64, and iOS Simulator Arm64 while keeping Android `Typeface` overloads source-compatible.
- Keeps the base `orca-core` and `orca-compose` artifacts free from optional math and font dependencies.
- Extends CI and release verification to compile the math adapter on Desktop and iOS Simulator in addition to Android.
