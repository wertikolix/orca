# Orca 0.10.0 (planned)

This next minor release starts the ultra-light architecture work by making image loading fully optional.

## Highlights

- Removes Coil and Ktor from the base `orca-compose` runtime graph.
- Adds `orca-images-coil` as an opt-in module for block and inline images.
- Adds explicit `imageContent` and `inlineImageContent` slots, while keeping alt/fallback text when no loader is installed.
- Preserves the safe-by-default remote-image policy introduced in `0.9.5`.

## Migration note

Applications that enable remote images must also provide image slots, either from `orca-images-coil` or their own loader implementation.
