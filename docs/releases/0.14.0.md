# Orca 0.14.0

## Highlights

- **Inserted/underline inline** — new `++text++` syntax parses into `OrcaInline.Underline` and renders with `OrcaInlineStyle.underline`. Works inside bold, links, and combines with `==highlight==`, `^sup^`, and `~sub~`.
- **Image captions** — the standard Markdown image title (`![alt](url "title")`) now renders as a caption below block images. Control it with `OrcaImageStyle.showCaption`, `captionText`, and `captionSpacing`.
- **Interactive task lists** — pass `onTaskToggle` to any `Orca` overload to make `- [ ]` checkboxes tappable. The callback receives the document-order task index and the requested state; the host rewrites the source. Rendering stays stateless — no extra dependencies, no gradients, no shadows.
- **Theme-aware inline HTML** — `<mark>`, `<kbd>`, `<u>`/`<ins>`, `<sup>`, and `<sub>` now derive from `OrcaStyle` instead of hardcoded light-theme colors, fixing unreadable spans in dark themes. `OrcaInlineStyle` gains `underline` and `kbd` fields, with dark defaults in `OrcaDefaults.darkStyle()`.
- **Material 3 adapter** — `materialStyle()` maps the new kbd and image-caption styles onto color-scheme tokens.

## Fixes

- Sample app: white status bar on dark theme. The sample now follows the system theme on first launch, re-applies `enableEdgeToEdge` system-bar styles whenever the in-app toggle changes, and ships a `values-night` window background so the first frame is dark too.
- `<mark>`/`<kbd>` spans were invisible or low-contrast in dark themes due to hardcoded light backgrounds.

## Migration

No breaking API changes for callers. Exhaustive `when` over `OrcaInline` in custom renderers needs a new `OrcaInline.Underline` branch.

```kotlin
Orca(
    markdown = markdown,
    parser = parser,
    onTaskToggle = { index, checked ->
        markdown = toggleTaskInSource(markdown, index, checked)
    },
)
```
