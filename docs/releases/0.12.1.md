# Orca 0.12.1

Patch release restoring stable initial layout for Markdown messages inside lazy chat lists.

## Fixed

- Parses the first `Orca(markdown = …)` frame synchronously again, avoiding an initial empty `OrcaDocument` that caused externally virtualized message bubbles to be measured at zero content height.
- Prevents visible empty messages and scroll-position jumps when scrolling to older content or regenerating an assistant response in clients such as Fish.
- Keeps subsequent streaming updates asynchronous and debounced as in `0.12.0`.
