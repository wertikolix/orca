# Orca 0.20.0

## Highlights

- **Complete nested render context:** table cells, definition terms, and details summaries now receive inline image, inline math, security, and inline override configuration. Rich content no longer falls back differently because it is nested.
- **Safe HTML media:** strict standalone `<img>` and `<figure>/<figcaption>` blocks route through `OrcaSecurityPolicy` and `imageContent`. Inline `<img>` routes through the same policy and `inlineImageContent`. Mixed or unsupported HTML remains readable text.
- **Inline renderer API:** every `Orca` overload accepts `inlineOverride`, an exact-class map from `OrcaInline` nodes to custom `AnnotatedString` output. Existing `blockOverride` behavior is unchanged.
- **Task renderer refresh:** task markers are platform-neutral flat checkboxes with semantics and a 40 dp interaction target. Hosts can replace them through `taskCheckboxContent` while retaining the stateless `onTaskToggle` contract.
- **Flat visual system:** quotes and admonitions use full one-pixel outlines and solid tinted surfaces. The Coil adapter replaces its shimmer gradient with a solid pulse loading state. No renderer adds shadows.
- **Table UX:** collection semantics identify table dimensions and cells, inline media/math works inside cells, and a solid position indicator appears only when horizontal overflow exists.
- **Render lab redesign:** the Android sample now has nine focused suites, persistent wide-screen navigation, compact mobile tabs, secure media and renderer API demos, controllable streaming, and a responsive source/preview playground.
- **Release hardening:** tag versions must match `orcaVersion`; missing Central or signing secrets fail the release; manual workflow runs cannot create branch-named GitHub releases.

## New API

```kotlin
Orca(
    markdown = markdown,
    parser = parser,
    inlineOverride = mapOf(
        OrcaInline.Abbreviation::class to { inline ->
            val abbreviation = inline as OrcaInline.Abbreviation
            AnnotatedString("${abbreviation.text} (${abbreviation.title})")
        },
    ),
    taskCheckboxContent = { checked, enabled, onCheckedChange ->
        ProductCheckbox(checked, enabled, onCheckedChange)
    },
)
```

New style fields are available through `OrcaQuoteStyle`, `OrcaTableStyle`, `OrcaAdmonitionStyle`, and `OrcaTaskStyle`. The Material 3 adapter maps every new visual role from the active color scheme and shapes.

## Migration

All new `Orca` parameters and style fields have defaults. Existing named calls remain source-compatible. Quote and admonition defaults intentionally change from a side stripe to a full outline. Legacy `stripeColor`, `stripeWidth`, and `spacing` fields remain present for source compatibility, but the 0.20 renderer uses the new full-container fields.

The optional Coil loading state now uses a solid pulse instead of a gradient shimmer. Applications with screenshot tests should update those snapshots.
