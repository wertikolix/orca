# Orca 0.13.0

## Highlights

- Exposes `LazyListState` through every `Orca` overload for synchronized fast scrollbars and external scroll controls.
- Adds the opt-in `orca-compose-material3` artifact with `rememberOrcaMaterialStyle()`, deriving Markdown colors, typography, and shapes from `MaterialTheme` without bloating the base renderer.
- Splits code-block language labels and copy actions into `OrcaCodeLabelStyle` and `OrcaCodeActionStyle`.
- Adds table row surfaces, alternating row surfaces, container shape, and a dedicated outer border color.

## Migration

`OrcaCodeBlockStyle.languageLabel` now accepts `OrcaCodeLabelStyle` instead of `TextStyle`. Move label-specific background, shape, and padding into that style. Configure the copy action independently through `copyButton`.

```kotlin
OrcaCodeBlockStyle(
    languageLabel = OrcaCodeLabelStyle(...),
    copyButton = OrcaCodeActionStyle(...),
)
```
